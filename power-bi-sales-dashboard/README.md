# Power BI Sales Dashboard

## Overview
Interactive dashboard analyzing sales performance, profit trends, and regional insights.

## Key Metrics
- Total Sales
- Total Profit
- Profit Margin
- Product Performance

## Insights
- Electronics dominate revenue
- South region performs best
- Certain products drive majority of profit

## Tools Used
- Power BI (Inspiration)
- React / Tailwind CSS (Implementation)
- Recharts for Data Visualization
- DAX Measures (Simulated via TypeScript Logic)
